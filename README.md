# Employee Management System — SQL & Power BI

## 📌 Project Overview

The Employee Management System is a data analytics project developed using **MySQL, SQL, Power BI, and DAX**. The project focuses on managing and analyzing employee-related information, including departments, salaries, qualifications, leaves, and payroll.

The objective is to transform relational data into meaningful business insights through SQL queries and an interactive Power BI dashboard.

## 🎯 Project Objectives

- Analyze employee distribution across departments.
- Calculate employee headcount and average salary.
- Analyze annual salaries, bonuses, and total payroll.
- Understand employee age distribution.
- Analyze leave information and employee-related trends.
- Build an interactive Power BI dashboard for HR and payroll analysis.

## 🛠️ Tools & Technologies

- **Database:** MySQL
- **Query Language:** SQL
- **Data Visualization:** Microsoft Power BI
- **Calculations:** DAX
- **Data Modeling:** Relational Data Modeling

## 🗄️ Database Design

The database consists of six relational tables:

1. **Employees** — Employee information.
2. **Departments** — Department details.
3. **Salary** — Employee salary information.
4. **Qualifications** — Employee educational qualifications.
5. **Leaves** — Employee leave records.
6. **Payroll** — Payroll-related information.

These tables support structured storage and analysis of employee and payroll data.

## 🔍 SQL Analysis

SQL was used to retrieve, combine, summarize, and analyze data from the relational database.

Key SQL concepts used:

- SELECT, WHERE, ORDER BY
- INNER JOIN and LEFT JOIN
- GROUP BY and HAVING
- Aggregate functions
- Subqueries
- Common Table Expressions (CTEs)
- Window functions
- Data filtering and sorting

## 📊 Power BI Dashboard

An interactive dashboard was developed to present employee and payroll metrics.

### Key Performance Indicators (KPIs)

- Total Employees
- Average Salary
- Total Annual Salary
- Total Bonus
- Total Payroll
- Average Age

### Analysis Areas

- Employee headcount and department distribution
- Salary and bonus analysis
- Payroll analysis
- Employee age analysis
- Leave analysis
- Department-level comparisons

## 🧮 DAX Measures

DAX measures were created to calculate key business metrics, including:

- Total Employees
- Average Salary
- Total Annual Salary
- Total Bonus
- Total Payroll
- Average Age

These measures support dynamic calculations based on report filters and selections.

## 🔄 Project Workflow

1. Designed a relational database using MySQL.
2. Organized employee information across six related tables.
3. Wrote SQL queries to analyze employee and payroll data.
4. Connected the data to Power BI.
5. Created DAX measures for key performance indicators.
6. Developed interactive visualizations and dashboard reports.
7. Analyzed employee, department, salary, payroll, and leave information.
